## Recomendacao de versionamento

Para salvar tudo de forma completa e segura:

1. usar Git LFS para PDFs, DOCX, PNG e JPG;
2. criar pasta exports para PDFs/DOCX;
3. criar pasta reports para relatorios;
4. criar pasta assets para capas/imagens;
5. criar pasta qa para contact sheets;
6. manter este inventario atualizado a cada nova passada.
